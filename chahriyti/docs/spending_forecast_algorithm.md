# خوارزمية توقع نهاية الدورة

## الهدف

بطاقة **توقع نهاية الدورة** تجيب على سؤال واحد:
> *إذا واصلت الإنفاق بنفس الوتيرة الحالية، كم ستكون مجمل نفقاتك في نهاية الدورة؟*

---

## المدخلات

| المتغير | المصدر | المعنى |
|---|---|---|
| `salaryAmount` | الدورة النشطة | الراتب الإجمالي |
| `salarySplitAmount` | الدورة النشطة | المبلغ المخصص للادخار |
| `totalSpent` | مجموع النفقات | ما أُنفق فعلياً حتى اليوم |
| `startDate` / `endDate` | الدورة النشطة | تاريخ بداية ونهاية الدورة |

---

## خطوات الحساب

### 1. الميزانية القابلة للإنفاق

```
spendableBudget = salaryAmount − salarySplitAmount
```

> مثال: 80,000 − 60,000 = **20,000 دج**

---

### 2. الأيام

```
totalDays    = (endDate − startDate) + 1
daysElapsed  = (اليوم − startDate) + 1   ← لا يقل عن 1
daysRemaining = totalDays − daysElapsed  ← لا يقل عن 0
```

---

### 3. معدل الإنفاق اليومي

```
dailyRate = totalSpent ÷ daysElapsed
```

> كم أُنفق في المتوسط كل يوم حتى الآن؟

---

### 4. التوقع (Projection)

```
projectedTotal = totalSpent + (dailyRate × daysRemaining)
```

> الإنفاق الفعلي حتى الآن + ما سيُنفق في الأيام المتبقية بنفس الوتيرة

---

### 5. نسبة التوقع

```
projectedRatio = projectedTotal ÷ spendableBudget
```

---

## الحكم على النتيجة

| الشرط | الحالة | اللون |
|---|---|---|
| `projectedRatio > 1.0` | تجاوز الميزانية | 🔴 أحمر |
| `0.9 ≤ projectedRatio ≤ 1.0` | قريب من الميزانية | 🟡 برتقالي |
| `projectedRatio < 0.9` | ضمن الميزانية | 🟢 أخضر |

---

## مثال عملي

| | القيمة |
|---|---|
| الراتب | 80,000 دج |
| الادخار | 60,000 دج |
| **الميزانية القابلة للإنفاق** | **20,000 دج** |
| أيام الدورة | 30 يوم |
| أيام مضت | 19 يوم |
| أيام متبقية | 11 يوم |
| ما أُنفق حتى الآن | 2,000 دج |
| معدل يومي | 2,000 ÷ 19 ≈ 105 دج/يوم |
| **التوقع** | 2,000 + (105 × 11) ≈ **3,157 دج** |
| نسبة التوقع | 3,157 ÷ 20,000 ≈ 15.8% |
| **الحكم** | ✅ **ضمن الميزانية** |

---

## ملاحظات

- إذا كان `daysElapsed = 0` (أول يوم) → `dailyRate = 0` → `projectedTotal = 0`
- إذا كان `daysRemaining = 0` (آخر يوم) → `projectedTotal = totalSpent` (ما أُنفق هو التوقع النهائي)
- إذا كان `spendableBudget ≤ 0` → لا تُعرض البطاقة
